# testpkg.full

[![CRAN status](https://www.r-pkg.org/badges/version/testpkg.full)](https://cran.r-project.org/package=testpkg.full)
[![R-CMD-check](https://github.com/testuser/testpkg.full/actions/workflows/R-CMD-check.yaml/badge.svg)](https://github.com/testuser/testpkg.full/actions)

A fixture package that exercises every part of the starlightdown pipeline:
Rd rendering, reference selectors, executed examples, Quarto articles, news
and citation metadata.

![The project mark.](man/figures/mark.svg)

## Installation

```r
install.packages("testpkg.full")
```

## Usage

```r
library(testpkg.full)
full_add(1, 2)
```

See [the reference index](/reference/) for everything else.
